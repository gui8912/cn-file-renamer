# 中文文件批量改名器（1.2.3）

Windows 本地工具。针对中文文件名的批量规范化：中文数字转阿拉伯数字、繁简与异体字统一、
符号清洗、日期重排、可选的 AI 语义改名。**先预览、再确认、可回滚**。

零安装：只用 Python 标准库，不需要 `pip install` 任何东西（繁简字典已内置在 `vendor/`）。
项目代码采用 MIT 许可；内置 `zhconv 1.2.2` 同为 MIT，来源与许可证见 `vendor/README.md`。

## 从 GitHub 拉取到笔记本

仓库是私有的，笔记本上需要先登录有权限的 GitHub 账号：

```bat
git clone https://github.com/gui8912/cn-file-renamer.git
cd cn-file-renamer
```

然后双击 **`启动.bat`**，或执行 `python app.py`。**不需要 pip install 任何包。**
首次运行会在 `data/` 下自动生成配置，仓库不会带上个人目录授权或 API Key。

## 启动

双击 **`启动.bat`**，浏览器会自动打开本机页面。默认地址是
`http://127.0.0.1:8770/`；若端口被占用会在 8770–8799 间顺延，**以窗口显示的地址为准**。
关闭那个黑色命令行窗口即退出。同一份程序目录只允许一个服务实例。

也可以在终端里跑：

```bat
python app.py
```

要求 Python 3.9+。

## 第一次用：先授权目录

程序拒绝扫描任何未授权目录，防止误操作整个磁盘。

点右上角 **「目录授权」** → 输入或浏览选择要处理的目录 → 「添加」。
授权是**递归生效**的：授权 `D:\资料` 后，`D:\资料\2026\会议` 也能用。

系统目录（`C:\Windows`、`Program Files`、`AppData`、各盘根目录）**永远拒绝**，即使手动加白名单也不行。

## 使用流程

1. 选目录 → 「扫描」
2. 左侧勾选要用的规则，调参数；右侧表格实时看到 `原名 → 新名`
   > **规则开关和参数会自动记住上次状态**，打开或刷新页面都不用重新勾。
   > 存档在浏览器本地：`localStorage` 存完整状态，`cookie` 只存开关、用于服务台动态端口兜底
   > （换端口时 localStorage 读不到，cookie 不分端口）。不写服务端、不需要重启、不联网。
   > 首次使用、换浏览器或清空站点数据后为**全关**；「全开 / 全关」按钮在左栏顶部。
   > 只记规则：含子目录 / 包含文件夹 / 冲突自动加序号等会话级开关刷新后仍归零，避免意外递归扫全盘。
   > 全关时预览条目都是「无变化」，勾上规则后才会出现「可改」条目。
3. 逐行核对。新名可以直接在表格里手改
   > 手工改过、导入对照表或 AI 写入的新名，之后调规则 / 排序 / 重新预览**都会保留**，
   > 不会被规则重算结果覆盖。想全部退回规则结果，点工具栏「↺ 恢复规则计算」（按钮上会显示手工条数）。
4. 勾选要执行的条目 → 「执行改名」→ 二次确认
   > 「全选 / 全不选 / ⇄ 反选」都只作用于**可改**且当前可见的条目：无变化、冲突、非法、
   > 以及被「按名称筛选」隐藏的行不会勾（勾了也执行不了）。操作后会提示勾了几条、
   > 剩下的为什么没勾。被筛选隐藏的行不会进入执行范围，清空「按名称筛选」可全部列出。
   > 表格「原文件名」列头可点击排序（再点切升/降序），与工具栏排序下拉框联动；
   > 排序会决定序号规则的先后顺序，所以会重新预览重算。
5. 改错了：点「历史与回滚」→ 对应记录 → 「回滚」

### 扫描筛选（按类型/通配符）

表格上方有「扫描筛选」：

- 只包含：`*.pdf;*.docx`，留空表示全部
- 排除：`~$*;*.tmp`
- 可省略 `*.`，直接写 `pdf;docx`
- 支持 `*` `?`，多个模式用分号、竖线分隔
- 修改后点「应用并重扫」

筛选只决定**哪些文件进入清单**；勾「包含文件夹」时目录仍会出现，便于单独整理目录名。
不带 `*` 的模式按“名称包含此文本”匹配（写 `2026` 可命中 `会议2026年总结`）。
表格右侧的「按名称筛选」只改变显示，不改变扫描范围。

> 如果换了目录却一条都扫不到，先看这两个框里是不是留着上次的模式（例如 `排除 *.mp4`
> 会把视频全排掉）。扫描结果为 0 且筛选非空时会明确提示，清空两个框再点「扫描」即可。

## 规则清单

按执行顺序排列（这个顺序有依赖，不是随便排的）：

> **Unicode 归一化**：规则 1「繁转简 + 异体字」会先做 NFC 归一化并统一不换行空格，
> 对标 PowerRename 的 `SanitizeAndNormalize()`。从 macOS / 网页拷来的文件名若把
> `café` 存成 `cafe` + 组合重音符（U+0301），符号清洗会把声调符删掉变成 `cafe`；
> 先合成才不会丢字。关闭规则 1 时不做此归一化。

| # | 规则 | 分组 | 作用 | 例子 |
|---|---|---|---|---|
| 1 | 繁转简 + 异体字 | 字符规范 | 繁体转简体，异体字归一 | `關於印發` → `关于印发`；`羣衆` → `群众` |
| 2 | 全角转半角 | 字符规范 | 全角字母数字标点转半角 | `ＡＢＣ１２３` → `ABC123` |
| 3 | 中文数字转阿拉伯 | 字符规范 | 数值读法 + 逐位读法 | `一百一十` → `110`；`一九九八` → `1998` |
| 4 | 查找替换 / 正则 | 替换 | PowerRename 式替换，`$1` 捕获组 | 见下节 |
| 5 | 去除噪声词 | 清洗 | 删掉复制残留 | `通知 副本(2)` → `通知` |
| 6 | 符号清洗 | 清洗 | 剔除全角符号、带圈数字、emoji | `图片①★说明` → `图片说明` |
| 7 | 生僻字处理 | 清洗 | 检出 GB2312 外汉字，可选删除 | 默认只提示 |
| 8 | 按分隔符保留 / 删除 | 重排 | 以某个字符串为界切一刀 | `纪要-2026年度` → `纪要` |
| 9 | 日期挪到最前 | 重排 | 识别日期并前移 | `会议纪要2026年10月29日` → `2026-10-29_会议纪要` |
| 10 | 收尾整理 | 重排 | 清空括号、首尾空格、重复分隔符 | `通知()` → `通知` |
| 11 | 英文大小写 | 重排 | 含 Title Case | `hello world` → `Hello World` |
| 12 | 按位置插入 / 删除 | 重排 | 位置支持负数（从末尾算） | 见下节 |
| 13 | 序号 | 收尾 | 起始值、步长、位置、按目录重排 | 见下节 |
| 14 | 数字补零 | 收尾 | 修掉「1、10、2」的排序错乱 | `文件1` → `文件001` |
| 15 | 前后缀 | 收尾 | 统一加前缀/后缀 | |
| 16 | 整名模板 | 收尾 | 变量 + 子串截取 | 见下节 |

### 查找替换 / 正则

对标 PowerRename。替换串里 `$1` 和 `\1` 两种写法都认，`${name}` 具名分组也支持。

| 查找 | 替换 | 效果 |
|---|---|---|
| `(\d{4})-(\d{2})-(\d{2})` | `$1年$2月$3日` | `2026-03-15` → `2026年03月15日` |
| `^` | `【加急】` | 在最前面插入 |
| `$` | `_已核对` | 在最后面追加 |
| `\s+` | `_` | 连续空白换成下划线 |
| `IMG_(\d+)` | `照片$1` | `IMG_0031` → `照片0031` |
| 一个空格 | **留空** | 删掉所有空格，`第九章 第一部分` → `第九章第一部分` |

**删空格**：在「查找」框里敲**一个空格**（看不见但确实在那），「替换为」留空即可；
想连制表符/全角空格一起删，查找填 `\s+`。查找框允许纯空白内容，不会被当成「没填」。

「替换全部」关掉时只替换第一个匹配（PowerRename 的 Match All Occurrences 同款行为）。

### 序号

`start` 起始值、`step` 步长、`digits` 位数（0 = 自动）、位置可放前或后。
勾「每个子目录重新计数」后，每个文件夹里都从起始值重新编号——按文件夹归卷时很有用。

### 模板变量与子串

```
{name} 当前主名        {old} 原始主名        {date} 识别出的日期
{ext}  扩展名          {parent} 父目录名     {grandparent} 上级目录
{mtime} 修改日期       {mtime_full} 含时分秒 {ctime} 创建日期
{year} {month} {day}   {size} {size_kb} {size_mb}   {index} {seq}
```

子串（对标 KRename 的 "using substrings of the old filename"）：

```
{name[0:4]}   取第 1-4 个字符
{name[:6]}    取前 6 个
{name[3:]}    去掉前 3 个
{name[-4:]}   取最后 4 个
{name[2]}     取第 3 个字符
```

### 数字补零

解决资源管理器按名称排序时 `1、10、2` 乱序的问题。默认**只补主名末尾的数字**（最安全），
年份 `2026` 这类四位数不会被补成 `0002026`。

```
文件1    → 文件001        IMG_2 → IMG_002        报告2026 → 报告2026（不动）
```

想补中间的数字（如 `第1卷 第2册`）就选「所有数字」模式，但要留意日期会被一起补。

### 按分隔符保留 / 删除

```
会议纪要-2026年度-草稿
  分隔符 "-" + 保留前面              → 会议纪要
  分隔符 "-" + 保留后面              → 2026年度-草稿
  分隔符 "-" + 取最后一个 + 保留后面 → 草稿

默认清洗会把 “ - ” 两侧空格收成 “-”，所以默认分隔符也是 “-”。
若关闭清洗并保留原空格，可把分隔符手动改成 “ - ”。
```

### 排序

工具栏的排序决定**序号的先后顺序**，所以必须在编号前确定。默认是「先按目录、再按名称」，
这样同一目录的文件会聚在一起，编号不会跨目录串。

### 只改主名 / 只改扩展名

对标 PowerRename 的 Item Name Only / Item Extension Only。
选「只改扩展名」时，规则作用在扩展名上（例如批量把 `.JPG` 改成 `.jpg`）。

### 导出清单 / 导入对照表

- **导出清单**：把勾选条目的 `原文件名,新文件名,目录,大小,修改时间` 导出成 CSV（带 BOM，Excel 直接打开不乱码），适合留痕。
- **导入对照表**：从 Excel 复制「原名 → 新名」两列直接粘贴，或按顺序对应。
  支持按原文件名匹配，或勾选「按顺序对应」第 N 行配第 N 个勾选项。只对已勾选条目生效。

### 中文数字的两套读法

这是最容易搞错的地方，所以分开实现：

- **数值读法**（按权位）：`一百一十`=110、`三百零五`=305、`壹佰壹拾`=110
  - 口语省略能处理：`一百一`=110、`一千五`=1500、`两百三`=230、`一万二`=12000
  - 有「零」占位时不补位：`一百零一`=101、`一千零五`=1005
- **逐位读法**（年份编号）：`一九九八`=1998、`二〇二六`=2026
  - 要求至少 3 个连续字，`二三` 这种歧义串不动
- **大数写法**：`壹佰壹拾万` → `110万`（可在参数里切成 `1100000`）

刻意保守：**默认不替换孤立单字**，所以「第一次」「第一章」不会被改成「第1次」「第1章」。

如果你整理的是培训课件 / 章节编号，想把「第一部分」「第三章」这类也统一成阿拉伯数字，
在「中文数字转阿拉伯」的参数里勾上 **「章节编号单字也转」**（默认关闭）。
它只认「第 + 单个中文数字 + 编号量词」这种明确语境，不会误伤「第一时间」「一览表」
「统一部署」「第一责任人」。

```
新版GMP体系文件训练营第十一章质量控制与产品放行 第一部分
  → 新版GMP体系文件训练营第11章质量控制与产品放行 第1部分
```

不勾这个开关时，`第十一章` 会转成 `第11章`，但 `第一部分` 保持原样——这是原设计。

## 安全机制

| 机制 | 说明 |
|---|---|
| 强制预览 | 任何改名都必须先生成预览表，不勾选不碰磁盘 |
| 二次确认 | 执行前弹窗确认目录与条目数 |
| 先写日志再动手 | 计划先落盘 `data/journals/*.json`，中途崩溃也能查、能回滚 |
| 两阶段改名 | 先全部改成临时名，再改成目标名。`a→b`、`b→a` 互换不会互相覆盖 |
| 一键回滚 | 按日志反向恢复，同样走两阶段；支持交换/链式改名与部分失败重试 |
| 文件身份校验 | 记录 NTFS file index；位置被外部替换的文件不会被误搬回原名 |
| 崩溃恢复 | 执行和回滚都在第一次 rename 前落盘临时计划，中途崩溃可继续恢复 |
| 父子路径互斥 | 同一批不允许目录与其内部条目混改，避免两阶段路径失效 |
| 目录白名单 | 未授权目录拒绝扫描 |
| 系统目录硬封锁 | 盘根目录永久拒绝；`C:\Windows`、`Program Files`、`AppData` 等系统目录及其子树拒绝 |
| 后端二次校验 | 前端传回的新名在后端重新过一遍非法字符、保留名、长度 |
| 仅本机访问 | 校验 Host / Origin，限制请求体大小，拒绝非法 JSON 与路径穿越 |

Windows 特有校验都做了：非法字符 `\ / : * ? " < > |`、保留名（`CON`、`PRN`、`AUX`、
`NUL`、`COM1-9`、`LPT1-9`，含 `CON.txt` 这种带扩展名的写法）、结尾不能是空格或句点、
单名不超过 255 个 UTF-16 单元、大小写不敏感的重名判定。

## 规则方案（可保存的组合）

左侧顶部「规则方案」下拉，把当前这一整套规则开关 + 参数存下来，下次换一批文件直接套用。
页面平时会自动记住上次勾选，方案主要用于在几套固定组合之间快速切换。

- 点「存」输入名字保存，同名覆盖；「删」移除选中方案
- 选中方案会自动套用并重算预览
- 存在 `data/presets.json`

典型用法：存一个「公文标准」（繁简 + 中文数字 + 日期前置），
再存一个「照片整理」（序号 + 补零）。

## 规则测试器

左侧「试一个名字，看规则效果…」输入框，边输入边显示处理结果——
不用扫描目录，也不用碰任何文件。调参数时最有用，改一个数字马上能看出差别。

## 噪声词库（可自己编辑）

「去除无意义噪声词」这条规则旁边有 **编辑词库** 按钮，点开可以自己增删。

- 用**空格**分隔（换行、逗号也认），可以直接从别处复制一整串粘进来
- **凡是进库的词一律从文件名里清除**
- 保存后立刻重算预览，不用重启
- 「恢复默认」可以撤销你的改动

英文词按**整词**匹配：`temp` 会把 `temp文件` 里的 temp 删掉，但**不会**误伤 `template`。
单字词（如「的」「一」）极易误伤正常文件名，界面上会警告。

## 把文件加进列表：三种方式

### ① 本地路径桥（推荐，全程不用碰路径文字）

双击项目根目录的 **`目录助手.bat`**，会弹出一个置顶小窗口「改名器 · 拖放助手」，三条路都能用：

- **「选择文件…（可多选）」按钮** → 弹出现代资源管理器式对话框，可一次框选多个文件
- **「选择文件夹…」按钮** → 弹出同一个现代对话框的文件夹模式
- **直接把文件/文件夹拖进窗口任意位置** → 老办法，仍保留

选完或拖完，真实路径自动送进改名器，当前页面 1~2 秒内自动刷新出列表。
**不新开标签页、不丢已调好的规则、不用粘贴**；窗口会显示加入了几条，关掉即退出。

顶部「**浏览…**」按钮用的是同一套现代文件夹对话框（Vista+ `IFileOpenDialog`，
带地址栏、搜索框、文件列表、快速访问），不再是老式树形框，**弹出时自动置顶**，
不会被浏览器窗口压在下面。
**下次打开会默认停在本次选过的文件夹**（记在 `data/bridge_state.json`，不进 git）。
选完自动完成授权 + 扫描 + 加入列表，一步到位。
「目录授权」弹窗里的「浏览…」只负责授权，不会改掉你正在处理的清单。

> 原理：浏览器出于安全**永远不向网页提供拖入文件的完整路径**，而原「浏览」依赖
> Tk 自绘的 `tk_chooseDirectory`，在中文 Windows 上常显示不出本地目录。
> `folder_bridge.py` 是独立本地进程，用 Win32 API（现代 `IFileOpenDialog` +
> `WM_DROPFILES` 拖放）拿到真实路径，经 127.0.0.1 交给服务。纯标准库 ctypes、
> 零 pip 依赖、不联网；现代接口不可用时自动回退老式目录框，保证至少能选。
> 无窗口自检：`python folder_bridge.py --selftest`（会显示 `IFileOpenDialog: OK`）。

### ② 网页内拖放（需先扫描）

浏览器里的拖放只拿得到「文件名 + 大小」，所以是在**已扫描**的清单里匹配：
文件不在当前扫描范围会提示先扫描所在目录；清单为空但顶部路径框已有目录时会自动补扫一次。

### ③ 粘贴路径

资源管理器里 Shift + 右键 →「复制为路径」，回到页面 **Ctrl + V**。能拿到完整路径。

| 方式 | 拿到绝对路径 | 需要先扫描目录 |
|---|---|---|
| ① 本地路径桥 | 是 | 否（会自动授权 + 扫描） |
| ② 网页内拖放 | 否（只有文件名+大小） | 是 |
| ③ 粘贴路径 | 是 | 目录需已授权 |

②③ 加入的条目会形成**聚焦**，只处理它们；点「显示全部」回到整个目录。

**清空列表**：清掉当前清单重新来过。只影响待处理清单，绝不碰磁盘上的文件。

## 资源管理器右键菜单

点顶栏 **「右键菜单」→ 安装右键菜单** 即可，装好之后：

- **右键文件夹** → 打开本工具并自动扫描该目录
- **文件夹空白处右键** → 同上
- **右键文件** → 把选中文件加入待改名列表；支持多选，一次打开一个页面

右键的目录会**自动加入授权白名单**，不用再手工「目录授权」。
如果服务没运行，会自动在后台拉起来（通常数秒内），再打开浏览器。

技术细节：

- 写在 `HKEY_CURRENT_USER\Software\Classes` 下，**不需要管理员权限**，换台电脑也能装
- 命令走 `pythonw.exe`，右键后不会弹出黑色控制台窗口
- 「右键菜单」面板会检查三个注册键是否齐全、命令是否仍指向当前目录；
  显示「部分安装」或「目录搬过家」提示时，重新点一次「安装右键菜单」即可
- 出问题看 `data/launcher.log`
- **目录搬家后要重新点一次安装**（注册表里记的是绝对路径）

同一弹窗里的「卸载」可以完全移除，不留残余。

## 设计参考

功能选型时对照了这些成熟的改名工具，各取所长：

| 工具 | 借鉴的点 |
|---|---|
| PowerRename（Microsoft PowerToys） | 查找替换 + 正则、只改主名 / 只改扩展名、替换全部开关、逐条预览与排除；`SanitizeAndNormalize()` 的 NFC/NBSP 前置归一化与逐条错误状态 |
| KRename（KDE） | 序号的起始值 / 步长、Title Case、文件元数据变量、取原文件名子串、插件式扩展 |
| Ant Renamer | 按位置插入 / 删除、字符规范化 |
| Advanced Renamer | 方法链、从外部列表导入改名对照 |
| ReNamer / Bulk Rename Utility | 规则链 + 预览 + 撤销的交互范式 |

### 与菲菲更名宝贝对照后的取舍

已具备的对应能力：规则链、正则、序号/补零、替换、删除与保留、大小写、模板变量、
预览与撤销、方案保存、文件列表导出、右键菜单、拖放。

本轮只补了一项贴合定位的功能：**按扩展名/名称通配符筛选扫描范围**。

明确不做：音乐标签、EXIF/GPS、Office/PDF 属性、文件时间与只读隐藏属性修改、
内码转换、文件名加密、Pascal/Python 脚本规则。这些要么会引入重量级依赖，
要么会把这把“文件名规范化工具”扩成通用文件属性编辑器，风险和收益不匹配。
汉字转拼音也按用户要求不加入。

## 已知限制

- 只改**文件名**，不改目录结构（包含文件夹时也只改文件夹名）
- 正在被程序占用的文件会失败，日志里记录失败原因，不影响其它条目
- `.tar.gz` 这类复合扩展名按最后一个点拆分
- 日期识别支持 `2026-10-29`、`2026年10月29日`、`20261029`、`10月29日`；
  没有年份的日期会用文件修改时间补年份
- 生僻字判据是 GB2312 编码测试（6763 常用字表），属于近似判断
- AI 改名需要模型能稳定输出 JSON 数组，小参数模型可能不稳定，建议用 7B 以上
- Windows 若未启用长路径支持，完整路径达到 260 字会在预览阶段标为非法；请缩短目录层级
- 不支持 UNC/网络共享路径，请先映射为本地盘符
- 同一时间只维护一份活动清单。两个标签页操作不同目录时，旧页面会被明确拒绝并要求重新扫描，**不会**把规则误套到另一个目录
- 改名和回滚都支持中断恢复；若磁盘上的文件被外部程序替换，工具会按文件身份拒绝搬动，需人工核对
- 不做 EXIF/音乐标签/Office 属性改名，也不修改文件时间或只读隐藏属性；这些超出“文件名规范化”的定位
- Unicode NFC 归一化搭在规则 1「繁转简 + 异体字」上，关掉该规则后不做归一化
